## Tue Oct 27 00:52:26 EDT 2026 -- encoding that works: exhaustive path enumeration
Attempts 4-5 (single Z3 formula for the whole unrolled controller): class-based leg fractions with dt in the advance, then fixed-rate integration with push_ite_arith lifting: tube at tick 2 and the reach query stay unknown at 120 s (H=2..8). Diagnosis: every product of a branch-dependent scalar with a coordinate is a nonlinear monomial for the solver, although along each branch the scalar is a rational constant.
Fix (kept): (a) the controller tests leg lengths only through comparisons (|d|_inf<=c as four linear atoms), never computes a norm value; leg fractions advance by speed x nominal tick / class bound (length classes of D=10 m), so along every branch the leg fractions are rationals and the target is linear in (w,p0); (b) bounded model checking by exhaustive path enumeration: the same controller code runs on a Fork arithmetic that splits on every symbolic branch, Z3 prunes infeasible branches, and per path Z3 decides the tube atom at every tick and the reach atom. Result on the prototype: H=2 110 paths 1.9 s; H=8 rho=1.0 certified (tube and reach) in 3.8 s; rho=0.9 fails at tick 2 (sat); H=16 6.0 s. Reach fails at H=2 and H=4 (mission not finished), as expected.
Deviation from ArduPilot recorded: kinematics integrated with the nominal tick (fixed rate); measured dt only clamps, and a tick whose dt the clamp changes is held. This keeps the geometry dt-free along each branch.

## Tue Oct 27 03:13:52 EDT 2026 -- monolithic timeout was an atom-order artefact; fix and rerun

My reported "timeout at 600 s" came from the order of the property queries in mono_check (fence tick by tick from tick 0, goal as one conjunction over all ticks): on some path the conjunction query is hard for Z3 while a single last-tick query settles the path at once. Fix in scripts/validate.py: mono_check(order='fair') is now the reported monolithic check (own implementation, same Fork machinery, same solver settings, 600 s limit): fence as one disjunction over the ticks of a path; goal first for single ticks from the last backwards (unsat for one tick settles the path, sound), then the conjunction. order='orig' is kept and measured as "goal atom tick by tick from tick 0" (fence per tick, goal conjunction) to document the effect.
