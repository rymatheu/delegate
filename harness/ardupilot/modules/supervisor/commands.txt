# The supervisor's commands as fields: which stand-in call (Class::method, in the command log)
# becomes which consumer's command fields. gen/gen_commands.py turns this into gen/Commands.lean
# (the output fields) and gen/out/cmd_emit.inc (filling them from the log).
#
#   Class::method -> stage field_method : arg arg ...
#
# Each arg names one word of the log entry in order (the stand-in records its arguments in
# declaration order, vectors component-wise, Location as lat, lng, alt_cm, frame): name:t with t
# f (f32), b (bool), u (u32), i (i32); "-" skips a word. Every target gets cmd_<stage>_<method>
# (bool), cmd_<stage>_<method>_seq (u32: position of the call in this tick's log, from 1, across
# all stages; 0 = not called) and cmd_<stage>_<method>_<arg>. Several sources may feed one target
# (the _loc forms of AC_WPNav are recorded under their NED names by stand_ins/stubs_guidance.cpp).
# Consumer names: modules/{position,attitude,guidance}/Module.lean of the integration copy.
