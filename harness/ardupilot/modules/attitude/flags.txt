# Compile flags of the attitude module, added to the shared ones in ardupilot/build.sh (as the
# mixer's flags.txt).
# AC_AttitudeControl and AP_Motors use APM_BUILD_TYPE(...), which needs the vehicle the library is
# built for; waf defines it per vehicle (Tools/ardupilotwaf/ardupilotwaf.py). For the attitude
# controller it selects Copter's INPUT_TC default (0.1), the 10 degree minimum lean limit and
# AC_ATTITUDE_CONTROL_AFTER_RATE_CONTROL = 1 (the controller reads the gyro the rate controller
# used, _rate_gyro_rads, not the AHRS) (AC_AttitudeControl.cpp:9-19).
-DAPM_BUILD_DIRECTORY=APM_BUILD_ArduCopter
# The SITL board's configure step defines AP_SIM_ENABLED (Tools/ardupilotwaf/boards.py, class sitl,
# cfg.define('AP_SIM_ENABLED', 1)) in waf's ap_config.h, which ardupilot/build.sh does not write;
# AP_AHRS.h uses it in an expression, so it must be defined.
-DAP_SIM_ENABLED=1
