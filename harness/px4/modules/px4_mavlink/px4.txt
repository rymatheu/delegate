# px4_mavlink: PX4's MAVLink module (src/modules/mavlink), unmodified: the code that speaks to
# QGroundControl (heartbeat and telemetry streams, parameters, missions, commands, FTP, ...).
# Started as on a serial link, `mavlink start -d /dev/ttyHARNESS0 -b 921600` (mode normal): the
# device is a byte-stream port of the harness (px4/shim/stream.cpp), 128 words = 512 bytes per
# tick each way. Three task-like activities, all run by the shim: the module's task
# (Mavlink::task_main: streams and sends, px4_usleep paced), and its receiver thread
# (MavlinkReceiver::run, pthread_create: poll on the port, parse, handle). Read by
# px4/ports.py and px4/build.sh; px4/modules/px4_mavlink/generate.sh makes the generated
# headers (PX4's own generators). Paths relative to $PX4_ROOT.
main mavlink
args -d /dev/ttyHARNESS0 -b 921600       # mode normal, the default (there is no "-m normal")
start dataman -r                           # the mission manager's storage (see Module.lean)
run mavlink boot_complete
process fresh
stream mavlink /dev/ttyHARNESS0 128
